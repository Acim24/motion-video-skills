# Audio guide

## Settings (`storyboard.audio`)

| field | default | notes |
|---|---|---|
| `music` | `'generated'` | `'generated'` = synthesized score fitted to the timeline; `'track.mp3'` = file in `public/`; `'none'` |
| `key` | `'D'` | root of the generated score. D/F/Bb feel warm; E/A brighter |
| `musicVolume` | `0.55` | bed level when nobody is speaking |
| `duckTo` | `0.35` | music multiplier under narration (0.25 = stronger dip, 0.5 = gentle) |
| `sfx` | `true` | synced UI sound effects |
| `sfxVolume` | `0.5` | 0.3–0.6 is the useful range; SFX should be felt, not noticed |
| `voice` | `'id-ID-ArdiNeural'` | any edge-tts voice |
| `voiceRate` | `'-4%'` | slightly slower than default reads as calmer and more premium |
| `voiceVolume` | `1` | |

Final loudness is normalized afterwards by `npm run master`, so balance the parts against each other rather than chasing absolute levels.

## Voices (edge-tts)

List all: `edge-tts --list-voices`. Good picks for this style:

- Indonesian: `id-ID-ArdiNeural` (male, calm), `id-ID-GadisNeural` (female, friendly)
- English: `en-US-AndrewNeural` (warm, confident), `en-US-AvaNeural` (expressive), `en-US-BrianNeural` (casual), `en-GB-RyanNeural`, `en-GB-SoniaNeural`
- Multilingual voices (`en-US-AndrewMultilingualNeural`, `en-US-AvaMultilingualNeural`) can read other languages with one consistent voice.

Match the voice language to the `vo` text language. Narration is cached by (voice, rate, text) in `public/vo/`, so re-running `npm run audio` only synthesizes changed lines.

## Writing narration

- **Narration complements the screen, it doesn't read it.** If the headline says "Inilah Nova 2", the VO can say it once; for benchmark/feature scenes, say the takeaway, not the numbers on screen.
- One short sentence per scene, max two. Pace ≈ 2.3 words/second for Indonesian, ≈ 2.6 for English at `-4%`. A 4-second scene fits ~9 words.
- Write numbers and versions the way they should be spoken: `Nova dua`, `delapan puluh dua persen`, `GPT four` — TTS reads "2" and "82.4%" unpredictably.
- Short sentences with periods give natural pauses; commas give small breaths. Avoid parentheses, slashes, emoji, abbreviations.
- Leave at least one scene without narration (often `bigNumber`) and always the `logo` — silence lets the music and SFX land.
- Typical 30 s film: 4–5 narrated scenes, ~45–60 words total.

## Using a recorded voice-over instead of TTS

Put files in `public/vo/` and, after `npm run audio`, edit `src/generated/audio-manifest.json` so `vo["<scene index>"] = {"file": "vo/my-line.wav", "seconds": <length>}` (get length with `ffprobe -v error -show_entries format=duration -of csv=p=0 file`). Remove `vo` text from those scenes in the storyboard first, otherwise the next `npm run audio` overwrites the manifest. For one continuous recording, set `music: 'none'` if needed and add it as a single `<Audio>` in `Video.tsx` instead.

## How sync works

- Scene components place `<Sfx name=... at={frame} />` next to the animation they belong to (`src/audio/Sfx.tsx`). Change animation timing and the sound moves with it. Looping sounds (`type`, `count`) take a `length`.
- Available SFX: `whoosh tick pop type count chime impact shimmer swell` (generated by `scripts/sfx.ts`; `swell` is unused by default — a rising whoosh you can end on a hit).
- `Video.tsx` adds a whoosh under every cut, starts each scene's narration `VO_LEAD` frames in, and ducks the music using the narration intervals (`src/audio/duck.ts`).
- `scripts/music.ts` receives scene start times; the build begins at the scene before the logo, and the tonic hit lands exactly on the logo's first frame. If you add a scene after the logo, the hit still targets the last `logo` scene.

## Tuning the generated score

All in `scripts/music.ts`: `BPM` (84 — calm), `PROGRESSION` (I–vi–IV–Vsus in maj9 voicings), arpeggio `density` per section, pulse gain, riser length. For a darker mood use a minor progression, e.g. `[[0,3,7,10,14],[-4,0,3,7,10],[-9,-5,-2,3,7],[-5,-1,2,5,9]]` (i–VI–III–V). Keep it sparse: the score sits under narration.

## Troubleshooting

- *edge-tts fails*: needs internet; install with `pipx install edge-tts` or set `EDGE_TTS=/path/to/edge-tts`. Without it, remove `vo` fields and the rest still works.
- *Narration sounds rushed*: lower `voiceRate` (`-8%`) or shorten the line; don't shrink the scene.
- *Music too busy under voice*: lower `duckTo` to 0.25 or `musicVolume` to 0.4.
- *Clicks at loop points in typing*: lengthen the chat scene so the typing window is longer than ~0.5 s, or lower `sfxVolume`.
